# AIstock — 無料のAI勉強コミュニティ

「何から始めればいい？」から、最初の「できた」へ。みんなの投稿を見て、気になる使い方を保存し、無料のWeb教科書で試せるアプリです。運営はMON-ai。旧・藤本実学塾とAitockを、この一つの本体へ統合しています。

## 開発

Node.js 22.13以上と、コミット済みのnpm lockfileを使います。

```bash
npm ci
npm run db:migrate:local
npm run doctor
npm run dev
```

`db:migrate:local`はローカルD1だけを対象にします。`npm run verify`で教科書・認証・コミュニティ・UIの基本条件・停止中の有料API・ビルドを検証します。`npm run check:ui`はナビゲーション・キャッシュ禁止・文字色の検査です。lintは独立した検査です。

画面設計は写真主体のフィードと、コンパクトな共通操作を軸にしています。スマホのアイコンナビ、開閉式の投稿フィルター、本文16px・操作44px以上、動きを減らす設定を維持します。対応ブラウザーのみページ切替を短いフェードにします。詳細は[デザイン方針](docs/AISTOCK_DESIGN.md)を参照してください。

教科書検索は12件ずつ、検索語と対象を保ったままページを送れます。フォロー欄の空表示は状態別に1つの案内にし、保存直後には保存一覧へのリンクを表示。有効な関連課題のある会員・公式AI投稿からは、教科書を新しいタブで開けます。HTTPの読み取り確認は `npx tsx scripts/check_discovery_http.ts http://localhost:3101`（起動したURLに合わせる）で実行します。実ブラウザーの操作検証とは別です。

## どこを編集するか

| 場所                    | 内容                                          |
| ----------------------- | --------------------------------------------- |
| `app/`・`components/`   | フィード、検索、学ぶ、会員ページ              |
| `lib/textbook-lessons/` | 全730課題・73章の完成本文。統合で上書きしない |
| `lib/official-posts.ts` | 実在教材への公式紹介。架空の生徒投稿ではない  |
| `db/`・`drizzle/`       | D1のデータ操作と追加マイグレーション          |
| `features/paid-school/` | 停止した有料画面の復元用                      |
| `archives/`             | 旧Aitockソース。Git・ビルド・公開対象外       |

保存、自分用ノート、教材の完了記録はD1へ。投稿画像はR2へ保管し、公開状態を確認して配信します。自分用ノートは公開投稿と独立しています。

マイページは投稿グリッド・保存・学習・成果物・設定の切替式です。公開プロフィール、フォロー、いいね、コメント、リンク共有、承認付きDMもD1で管理します。仕様と公開前の確認項目は[交流機能](docs/AISTOCK_SOCIAL.md)を参照してください。公式AI10人と投稿例をローカルに準備するには、マイグレーション後に `npx tsx scripts/seed_official_local.ts` を実行します。実会員の認証アカウントは作りません。

現在のソースでは、表示名・重複しないユーザーID（半角英数字・`_`・`-`、3〜24文字）・8文字以上のパスワード・規約同意で無料登録できます。メール・本名は不要。IDは`/u/ID`のURLと`@ID`でのログインに使い、名前・ID・写真はマイページのプロフィール編集へ集約しています。プロフィール公開と復旧コードは任意です。変更前のIDは他人に再利用させず、旧URLは公開中だけ現在のURLへ案内します。既存の非公開ログイン名はそのまま使え、勝手に公開しません。

新ID・写真のコードには既存の`AUTH_PASSWORD_PEPPER`とD1の0019までが必要です。本番は0018までの旧登録仕様で、登録・マイページ・ログアウト後の旧セッション拒否・再ログインをHTTP検証済みです。新仕様の本番確認はまだです。Google・メール登録は未設定のため表示しません。秘密情報をGitやチャットへ貼らないでください。実ブラウザー操作や2人の実会員によるDM確認は別の確認項目です。

公式の公開データは追加migration `0018_official_launch_seed.sql`で導入します。ログイン会員を作らず、既存会員・同意記録を変更しません。公開記録と残りの運用確認は[引き継ぎ](docs/HANDOFF.md)を参照してください。
