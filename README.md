## 会員認証と初回オンボーディング

新規会員はSign in with ChatGPTでメールアドレスの本人確認を行い、その後は登録したログインIDとパスワードで利用します。初回パスワードには登録時に入力した生年月日8桁を使いますが、初回利用時は同じメールアドレスのChatGPT本人確認も重ねて行います。運営者だけは、`ADMIN_EMAILS`で確認済みの本人と`AUTH_OWNER_LOGIN_ID`で指定した塾ログインIDを安全に結び付けられます。初回パスワードは発行から72時間で失効し、登録直後または初回ログイン時に本人専用のパスワードへ変更するまでマイページは使えません。生年月日そのものと入力した8桁は保存せず、パスワードとセッショントークンはハッシュ値だけをD1に保存します。ログインの回数制限ではIPアドレスを一時的に処理しますが、IPアドレスそのものは保存せず、秘密情報で保護した識別子とログイン試行回数だけを保存します。

初回オンボーディングでは、表示名に加え、学びたい目的、選んだ始め方、興味分野、最初に作りたい物を登録します。デモアカウントは表示確認専用で、申込、学習記録、プロフィール、管理データへの書込みをサーバー側で拒否します。パスワードを忘れた場合のメール相談は登録メールアドレスから受け付けますが、自動再設定メールと具体的な復旧方法は準備中です。ログインID、パスワード、初期化用トークンの実値は、コード、README、引き継ぎ資料、Git履歴に記録しません。

2026年9月3日に新認証をSites本番へ公開し、運営用と閲覧専用デモの初期アカウントを作成しました。本番で、運営者のChatGPT本人確認から初回パスワード変更画面まで、管理権限、デモログイン、デモによる9系統の書込み拒否、偽装本人確認ヘッダーの拒否を確認済みです。運営者本人による新しいパスワードの確定と、別の一般会員によるオンボーディング全行程は未実施です。初期化用トークンはSites環境から削除済みで、初期アカウント作成APIもデータ状態や環境変数に関係なく常に404を返す恒久停止としています。

全730タイトルと全73章見出しは、「完成物・使う場面・うれしい変化」が浮かぶワクワク基準へ統一しました。AIが初めてなら最初の一歩から一段ずつ、目的や経験がある人は今の自分に合う段階から、画像・資料・Excel・Web等の特化領域だけでも始められます。メール、毎朝の自分専用ニュース、経理表、PowerPoint、会社サイト、会員マイページ、ゲーム、スマホアプリ、本、画像、SNSまで、同じ作品を各章の01から10へ育てる構成です。共通編だけは作品の複雑さを示すLv.1〜200を持ち、部署・業種・生成特化は独立した選択コースです。

別リポジトリ『AI社員のつくり方大全』の109の問い、90日・13週間、18成果物は、事業者・法人の高度な業務実装を扱う別書籍の素材です。一般向け教材には未採用で、公開・配布・販売状態も要確認です。

`/textbook`はWeb教科書の使い方と練習データの説明、`/textbook/explore`は全730課題から「いま作りたい物」を目的・時間・作業画面・材料で探すページ、`/textbook/lesson/[taskId]`は1課題の本文に集中するページです。検索結果、コース、完成物のリンクは本文を新規タブで開きます。旧形式の`/textbook?task=ID`は、ブラウザに保存された旧URLや共有URLを壊さないよう、対応する本文ページへ互換リダイレクトします。課題ページは内容に合う架空会社を1社に自動で固定し、必要なファイルだけを直接表示します。短いTXTはその場で中身をコピーし、PDF・Word・Excel等は使う分だけを取得してChatGPTへ添付できます。業種選択やZIP展開は不要です。単発ならChat、Excel・PowerPoint・ホームページ・アプリ等の実ファイル制作や継続修正ならWorkをすすめますが、入力方法や作業画面は採点しません。全課題で、実操作、出力を上げるコツ、やりがちなミス、完成条件、保存、仕事への応用、「もう一つできること（任意）」まで表示します。本文は対象課題の章だけを読み込みます。ルート分離はローカルのデスクトップ幅・スマートフォン幅で表示、検索、新規タブ指定、本文のコピー・チェック・前後移動、旧URL互換、404まで確認済みです。正式URLでも3画面、新規タブ指定、旧URL互換、404、canonicalを確認済みです。実際のChatGPTを使う全課題の実行QAは未実施です。

`/level-test`はURL互換のため残す公開確認用デモです。Sitesの会員機能は、Sign in with ChatGPTを使う新規本人確認と、本人確認後のID・パスワードログインを併用します。D1には、初回同意、本人別`/mypage`、課題の「あとでやる」と本人完了記録、3方式の受講申込、AI実学パスポート、運営キューを保存します。会員は表示名の変更、課題のブックマーク・完了・未完了への戻し、未確定申込の取消、学習記録の差し戻し後の再提出ができます。完了は本人用メモで、出席、講師確認、修了認定とは分けます。運営は申込状態、会員向け案内、担当講師、JST実施日時、会場またはGoogle Meet、内部メモを一つのキューで管理します。学習記録は教科書課題または既存の実務・自主制作から作成でき、本人公開設定、講師確認、`noindex`のURL共有プロフィールへつながります。申込と講師確認は比較更新と追記型履歴を使い、自分の成果物の講師確認はサーバー側で拒否します。これは公的資格・公式認定・採用保証ではありません。申込は「希望受付」の保存であり、空き枠の確保、自動予約確定、決済、通知、教科書の読了位置・自動進捗保存はまだ行いません。

## 新しいMacで最初に行うこと

必要なものは、Git、Node.js 22.13以上、npm、GitHubへのアクセス権です。Codexで公開まで行う場合は、現在のSitesプロジェクトを操作できる同じChatGPT／Codexアカウントも必要です。

```bash
git clone https://github.com/fujimoto198904-hash/aijuku.git
cd aijuku
nvm install
nvm use
npm ci
npm run db:migrate:local
npm run doctor
npm run dev
```

`nvm`を使わない場合は、Node.js 22.13以上を別の方法でインストールしてください。起動後に http://localhost:3000 を開きます。3000番が使用中なら、次のように変更できます。

```bash
npm run dev -- --port 3001
```

一般ページの表示には環境変数は必須ではありません。Vercelビルド時だけ`/aijuku`が自動でURLへ付き、Sitesとローカルは従来どおりルートで動きます。ID・パスワード認証を使う場合は、Sitesの実行環境へ`AUTH_PASSWORD_PEPPER`を秘密値として設定します。初期アカウント作成APIは本番作成後に恒久停止し、`AUTH_BOOTSTRAP_TOKEN`も使用しません。管理画面を使う場合は、`ADMIN_EMAILS`（申込管理を含むオーナー）と`INSTRUCTOR_EMAILS`（成果物の講師確認のみ）を設定し、それぞれ許可する確認済みメールアドレスをカンマ区切りで登録します。管理者のChatGPT確認メールと塾ログインIDが異なる場合だけ`AUTH_OWNER_LOGIN_ID`も設定します。実値はGitへ保存しません。

```bash
cp .env.example .env.local
```

`db/schema.ts`と`drizzle/0001`〜`0003`には、提供を取りやめた第三者評価のテーブル定義が過去の適用履歴として残っています。既存DBのマイグレーション順序と互換性を守るため、過去のSQLは削除・書き換えしません。現行の画面とAPIは、これらのテーブルへ評価データを作成・読取・表示せず、第三者評価を提供済みと案内しません。旧リンクには非提供の案内を表示し、旧評価APIはHTTP 410を返します。

`drizzle/0007_nervous_ted_forrester.sql`は、無料会員本人の課題ブックマークと完了状態を保存する`member_lesson_progress`と、1会員あたりの書込回数を制限する`member_lesson_rate_limits`を追加します。完了は本人用の学習メモで、講師確認、出席、修了認定とは別です。Sites公開時に未適用のマイグレーションだけが新Workerより先に適用・記録されます。既存本番へ`0000`から手動で再実行せず、適用済みSQLは書き換えません。空DBへの初回公開時だけ全履歴が順に適用されます。

`drizzle/0008_oval_malice.sql`は、ID・パスワード認証アカウント、ハッシュ化したセッション、ログイン回数制限用の保護済み識別子と試行回数、初回オンボーディングの4項目を保存するテーブルを追加します。生年月日、初回入力の8桁、パスワード原文、セッショントークン原文、IPアドレスそのものは保存しません。空のローカルD1への全マイグレーション適用とSites本番への`0008`適用を行い、本番DBに4つの新テーブルがあることを2026年9月3日に確認しました。

`sozai/fujimoto-profile.webp`は、ユーザー本人から提供された藤本亮志のプロフィール写真をWeb表示用に軽量化したものです。独立した講師紹介セクションを外したため、現在の公開ページでは使用していません。その他の`sozai/`内の写真は、実際の講師・受講者ではなく、暮らし・仕事でAIを使う場面を示すイメージ素材です。継続公開や再利用の前に、各素材の取得元とWeb掲載を含む利用条件を確認してください。

## ChatGPTのプラン・作業環境表示

`/textbook/setup`でChatGPTの初期設定、無料・有料の違い、Chat・Work・Codexの使い分けを案内します。全730課題に「無料で始めやすい」または「有料版推奨」を表示し、Workでも進められる課題のうち、実ファイル・コード・テストを直接扱う時にCodexが特に向く課題には「Codex向き」を併記します。Codexは料金プラン名ではなく、現時点でCodexだけに限定した課題はありません。判定ルールは`lib/textbook-access.ts`、網羅検査は`npm run check:access`を正とします。

## 変更を保存する基本手順

以下は、変更内容を確認して`main`へ採用すると決めた後の通常手順です。検証と差分確認を終えてから、採用する変更だけをcommit・pushします。

作業開始時:

```bash
git pull --ff-only
npm ci
npm run db:migrate:local
npm run dev
```

新しいMacや空の`.wrangler/`では、`npm run db:migrate:local`がローカル専用D1へ未適用のSQLだけを適用します。本番D1には接続しません。マイグレーション管理済みのローカルD1へ新しいSQLを追加した後も、開発サーバー起動前に同じコマンドを実行してください。

旧実装がマイグレーション履歴なしで作ったローカルD1を検出した場合、スクリプトはデータを変更せず停止します。必要な試用データがあれば`.wrangler/state`を別名へ退避し、新しい空の`.wrangler/state`に対して再実行してください。自動削除は行いません。この退避はローカル試用データだけが対象で、本番の会員データには影響しません。

作業完了時:

```bash
npm run verify
git status
git add .
git commit -m "変更内容を簡潔に記載"
git push origin main
```

Vercel子アプリはGitHub `main`へのpushで自動公開され、親`mon-ai`のrewriteも別リポジトリで公開済みです。Sitesの公開は別作業です。会員機能の正本はSites本番で、運営用とデモ用のID・パスワード認証は本番確認済みです。別の一般会員によるオンボーディング全行程と、ログイン後の通常会員・講師操作は引き続き通しQAを行います。詳しい公開順、現在の実装状況、未実装機能、トラブル対応は[引き継ぎ資料](docs/HANDOFF.md)を参照してください。

会員Sitesの新機能と、それを案内するVercel公開面を同時に変更する場合は例外です。検証後に同じ内容を一つのcommitへまとめ、まずSitesのソースへ送り、Sites本番と会員E2Eを確認します。その成功後に同じcommitを`origin/main`へpushし、Vercelの案内を公開します。先に`origin/main`へpushすると、未公開の会員機能をVercelだけが案内する時間帯が生じます。
