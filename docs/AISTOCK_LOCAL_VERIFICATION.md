# AIstock ローカル検証

2026年9月5日。以下は今回の統合版のローカル検証です。本番公開や実会員による通し操作の証拠ではありません。

## 検証範囲

- `npm run verify`：教科書730件、メタデータ、利用プランマーク、認証、コミュニティ、旧決済／Calendarの安全性、資料リンク、コラム100件、練習データ、本番ビルド。
- `npx tsc --noEmit`：型検査。
- 新しい画面とAPIの対象限定lint：フォームのラベル、イベント型、状態通知などを修正。既存を含む全リポジトリのlintが正常という意味ではありません。
- 使い捨てD1/R2テスト：本人以外のノート参照・編集・削除の拒否、未公開ノートの公開検索除外、再送時の二重作成防止、同ID異内容の拒否、保存一覧の会員分離。
- Aitock取込：実践日と分類の維持、同じ記録の重複防止、違う内容の再取込で上書きしないこと、削除済み記録を復活させないこと。
- 画像：PNGの構造・容量・破損チェック、付帯情報の除去、公開前の本人限定配信、元投稿の非公開後の一般配信拒否。
- 登録：確認チケットの期限・一回利用・同時利用・乗っ取り拒否。Googleはローカル署名のテストデータで署名・nonce・発行元・対象アプリ・期限・メール確認を検査。Googleへの実通信ではありません。
- 有料API：DBやStripe、Calendarへ接続せず410で停止すること。
- HTTP：ホーム、検索、学ぶ、公式紹介、コミュニティ、実教材、登録画面が200。未ログインのノート・投稿作成はログインへ転送。新画面にAIstock表記を確認。
- 旧ソース108ファイル・参考資料50ファイルの移動前後SHA-256一致。元のパスも参照可能。
