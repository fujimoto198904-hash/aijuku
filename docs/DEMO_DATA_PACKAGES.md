# 練習用デモデータ3社パック

更新日: 2026年9月3日

状態: 課題別の直接取得用185素材をローカル生成・サイト組込み済み。Sites・Vercel反映は別作業

## 受講する人へ

資料を自分で集めなくても、すぐ練習を始められるように、美容室・建設業・不動産会社の架空データを用意しています。通常は会社を選びません。課題を開くと、内容に合う架空会社が一つに決まり、必要なファイルだけが表示されます。TXTはその場でコピー、PDF・Word・Excelなどは1件ずつ直接取得できます。3社のZIPは、同じ会社で多くの課題をまとめて練習する人向けの任意機能です。

### 最初の3分は、メールメモを貼るだけ

1. 教科書で`Lv.05`を開きます。
2. 「この課題で使うファイル」の`01メール.txt`で「中身をコピー」を押します。
3. ChatGPTを開き、メモ本文を貼った後へ次の一言を続けて送ります。

~~~text
--- ここからメモ ---
ここへ01メールの中身を貼る
--- ここまでメモ ---

これ、相手に返すメールにして。
ちょっと急ぎ。あんまり堅くしないで。まだ送らないで。
~~~

返ったメール下書きをコピーし、普段使うメモアプリまたは文書アプリへ保存します。準備完了の条件は次の三つです。

- 01メールの内容に合う下書きが返った
- メモにない相手名、約束、期限が勝手に増えていない
- 保存したメール下書きを自分で実際に開けた

### 材料の渡し方と、作る画面を分けます

1. **短い文章:** 中身をコピーして、そのままチャットへ貼ります。
2. **書式付き資料:** PDF、Word、Excel、画像等をチャットへ添付します。

短いメモと料金PDFを一緒に使う時は、メモ本文を貼り、PDFだけを添付します。単発ならChat、Excel・PowerPoint・ホームページ・アプリ等の実ファイルを作る、または何度も直すならWorkを使います。Workの入力欄でも、短文は貼り、書式資料は添付します。

Workで資料が見えなければ入力欄へ貼付・添付し、添付で読めなければ必要部分の貼り付けへすぐ切り替えます。スキャン資料は必要ページの画像でも構いません。「読めなかった資料名を教えて。内容は推測しないで」と伝えます。

どの方法を使っても、同じ完成条件なら合格です。入力方法や作業画面は採点しません。通常チャットや添付でできた物は、本人がコピーまたはダウンロードして`完成`へ保存します。WorkではAIへ保存を頼めますが、最後は本人がファイル管理画面から開きます。ChatとWorkの使い分けは[OpenAI公式案内](https://learn.chatgpt.com/docs/use-chatgpt)を参照します。

## フォルダの中身

解凍すると、業種名のフォルダが一つできます。

```text
美容室デモデータ／建設業デモデータ／不動産会社デモデータ
├── README_最初に読んでください.txt
├── 00_最初に見る
│   ├── 00_このデータは全部架空です.pdf
│   └── 00_ファイル早見表.xlsx
├── 課題
│   ├── 01メール.txt〜10AI安全.txt
│   ├── 11会社.pdf、12料金.pdf、13組織.pdf
│   └── 14AIルール.docx
├── 10_会社まるごと
│   └── 会社、社員、顧客、営業、売上、仕入、経理、電話、会議、集客、業種別のExcel
├── 20_Word
│   └── 会社ルール、仕事のやり方、ひな形、会議記録、電話記録
├── 30_PDF
│   └── 会社資料、月次資料、見積書、請求書、領収書など
├── 90_OCR練習PDF
├── 完成
├── 99_データ辞書
├── manifest.csv
└── SHA256SUMS.txt
```

最初は`課題`だけ見れば進められます。代表10課題で使う14ファイルは、すべてここに集めています。短文は中身を貼り、書式付き資料は添付します。実ファイルを作る、または何度も直す課題ではWorkを作業画面にします。会社全体のデータが必要な高度な課題では、教科書に`10_会社まるごと`以下のファイル名まで書きます。

## このデータの約束

- 会社、顧客、社員、取引先、住所、電話番号、メール、売上、契約、工事、物件はすべて架空です。
- メールは`example.invalid`、電話番号は`000`番号など、実在連絡先として使えない形にしています。
- 練習用データを、本物のお客様への連絡、契約、発注、振込、広告公開などへ使いません。
- 本物の顧客情報や社員情報を、このデモフォルダへ混ぜません。
- AIが作った答えはそのまま外へ送らず、人が相手、金額、日付、事実、公開範囲を確認します。
- 元データを残したい時は上書きせず、完成品を`完成`フォルダへ保存します。

### 更新時に確認すること

1. WindowsはZIPを右クリックして「すべて展開」、MacはZIPをダブルクリックし、展開後も3つのデモフォルダ名が変わらないことを確認します。
2. `課題/01メール.txt`の本文をコピーしてChatGPTへ貼り、内容に合う下書きが返り、メモにない相手名・約束・期限が増えていないことを確認します。
3. 返答を本人が`完成/メール.txt`へ保存し、Windowsはエクスプローラー、MacはFinderから実物を開けることを確認します。
4. PDF、Word、Excel、画像の代表資料を添付し、書式や表を含めて読めること、読めない場合に資料名を示して止まることを確認します。
5. WindowsとMacのChatGPTデスクトップでWorkからデモフォルダを開き、指定ファイルの読み込みと`完成`への保存を確認します。Workで読めない場合に添付または本文貼り付けへ切り替えて課題を続けられることも確認します。
6. 3つのZIPが開き、`ZipFile.testzip()`で破損がないことを確認します。
7. 各ZIPに156ファイル、`課題`内の教材用14ファイル、`完成`フォルダがあることを確認します。
8. `public/downloads/demo-data/SHA256SUMS.txt`と実際のZIPのSHA-256が一致することを確認します。
9. `catalog.json`の容量、Excel冊数、シート数、データ行数、Word数、PDF数と実物を照合します。
10. 実在の氏名、住所、電話番号、メール、口座、秘密情報が混ざっていないことを確認します。
11. ローカル表示の`/textbook#demo-data`で、3つのカード、MiB表記の容量、件数、リンク先、材料の渡し方と作業画面の違いを確認します。
12. `npm run verify`を実行します。この中で`npm run check:demo-data`も実行されます。GitHubへのpushとSites・Vercelへの公開は、それぞれ別作業です。
