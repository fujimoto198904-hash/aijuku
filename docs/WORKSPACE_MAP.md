## 復元が必要になった場合

1. `archives/aitock-2026-09-05/SHA256SUMS.json`で対象を確定し、旧アプリが停止していることを確認する。
2. 移動元が記録した移動先へのリンクであることを確認する。
3. リンクだけを外し、記録したファイル／フォルダを元へ戻す。移動先に変更がある場合は先に退避する。
4. 照合値、旧パス、依存ライブラリを検証する。復元前に`npm ci`や旧アプリの更新を実行しない。

今回削除した元データはありません。通常の開発は本体の`npm run dev`だけを使ってください。

## ブラウザー内の記録は別

Aitockの個人記録は各利用者のブラウザーにあり、作業フォルダにはありません。本人が旧サイトからJSONを書き出し、新しい無料会員の自分用ノートで選択して取り込みます。実践日・分類・工夫を維持し、同じ記録の重複、内容が違う再取込、削除済み記録を区別します。自動公開や、勝手な課題完了への変換は行いません。

旧ドメインの本人記録へのアクセス、書き出し画面の本番配置、実際の会員データ移行は未実施です。

書き出し補助は`migration/aitock-export.html`に用意しています。旧アプリの`public`へこの1ファイルを配置してから、利用者が以前使ったドメインで開きます。ローカルファイルや新しいドメインから旧localStorageを読むことはできません。補助ページは記録の読取り・本人へのダウンロードだけを行い、送信や削除はしません。
