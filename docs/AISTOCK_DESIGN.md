# AIstock デザインの現在地

2026年9月5日。ブランド、UI、動き・アクセシビリティの3視点でAIレビューし、その後の「ホームはInstagramを参考に」という指示を優先して調整しました。実在の外部デザイナーを雇用した記録ではありません。

## ホーム

Instagramの[公式フィード紹介](https://about.fb.com/news/2022/03/two-new-ways-to-control-your-instagram-feed/)を参照。ロゴや配色の複製ではなく、投稿者・画像・操作・本文を順に読める1列の構成を採用しています。

- 囲みカードと大きな影をホームでは外し、薄い区切り線で投稿をつなぐ。
- 写真は大きく、メール・会議・Excel・Webの教材紹介は内容がわかる例にする。写真も図も教材の説明用と明記する。
- 画像の下に実数の「いいね」「コメント」「シェア」「試す／読む」「保存」。架空のいいねや件数は作らない。
- PCは左ナビ、中央フィード。右の学習案内は幅1280pxから表示。スマホは下ナビにし、端末の安全領域を空ける。
- ロゴ表記はAIstock、読みはアイトック。深緑と白を軸にし、淡い色は教材や補助情報に使う。

検索と学ぶページは一覧として比較しやすいカードを維持します。ホームと全ページを機械的に同じ見た目にはしません。

## 動きと操作

最初の4投稿だけ短い順次表示。写真の小さな拡大、ボタンの押下、主ボタンの一度の光沢は操作に合わせます。保存の反応はAPI成功後だけで、失敗時はエラーを表示します。背景の常時点滅や、読むのを妨げる視差効果は使いません。

動きを減らす設定ではアニメーション・移動を止め、文言・枠・色で状態を伝えます。キーボードのフォーカス、強制配色、44pxの操作領域、小文字のコントラストも扱っています。

## データと確認範囲

マイページは大きなアバターと実数の投稿・フォロー数、その下に投稿グリッド／非公開の保存／学習／成果物／設定を置きます。切替中も既存フォームを保持し、学習・成果物・設定の直接リンクを維持。公開プロフィールとDMは[交流機能](AISTOCK_SOCIAL.md)の公開境界に従います。公式アカウントのアイコンは四芒星だけの丸から、深緑の角丸と「Ai」の文字を組み合わせた専用表示へ変更しました。

認証・保存一覧は各リクエストで取得し、カードには保存可能かとその投稿の保存状態だけを渡します。保存状態を含む公開ページにはキャッシュ禁止ヘッダーを設定し、公開ページの検索エンジン登録は妨げません。

`npm run check:ui`で主ナビの配下判定、公開ページの個人状態のキャッシュ禁止、主要な文字色のコントラストと動きのフォールバックを検査します。既存の認証・D1/R2検査とビルドも維持します。ブラウザーの実操作・スクリーンショットによる視覚検証、本番公開は今回未実施です。
