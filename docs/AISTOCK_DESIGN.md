# AIstock デザインの現在地

2026年9月5日。ブランド、UI、動き・アクセシビリティの3視点でAIレビューし、「ホームはInstagramを参考に」に加えて「セクションの境界と文字の強弱を明確に」という指示で調整しました。実在の外部デザイナーを雇用した記録ではありません。

## ホーム

Instagramの[公式フィード紹介](https://about.fb.com/news/2022/03/two-new-ways-to-control-your-instagram-feed/)を参照。ロゴや配色の複製ではなく、投稿者・画像・操作・本文を順に読める1列の構成を採用しています。

- 写真主体の1列フィードを維持。投稿は影を付けない白い面にし、PCは薄い枠と16pxの間隔、スマホは画面幅いっぱいの投稿と10pxの背景帯で次の投稿との境界を示す。
- 写真は大きく、メール・会議・Excel・Webの教材紹介は内容がわかる例にする。写真も図も教材の説明用と明記する。
- 画像の下に実数の「いいね」「コメント」「シェア」「試す／読む」「保存」。架空のいいねや件数は作らない。
- PCは左ナビ、中央フィード。右の学習案内は幅1280pxから表示。スマホは下ナビにし、端末の安全領域を空ける。
- ロゴ表記はAIstock、読みはアイトック。深緑と白を軸にし、淡い色は教材や補助情報に使う。

検索と学ぶページは一覧として比較しやすいカードを維持します。ホームと全ページを機械的に同じ見た目にはしません。

## 背景と文字の優先順位

- ページ背景は薄いグレーグリーン `#eef2ee`、操作・補助領域は `#e2ebe5`、読む内容は白。背景に加え、枠・余白・見出しでも区切りを伝える。
- フィードの見出しは18px。前置きのコピーを外し、フィードの選択と開閉式の「投稿を絞り込む」を1つの操作領域へ。種類を選んだURLでは最初から開き、現在の条件も表示する。右側の案内は淡い背景と18px見出しで控えめにする。
- 標準文字サイズでは、ページの案内見出し24〜30px、内容の区切り20px、投稿・教材の見出し18〜19px、本文16px。説明・操作は13〜14px、日付などのメタ情報は12〜13pxを目安にする。新たな文字指定は原則remとし、本文まで一律に縮小しない。
- 「見つける」は検索・キーワード・対象の切替をまとめ、キーワードは横にスクロールできる1列にする。結果一覧はこの領域の外へ置く。
- 「学ぶ」は教材を選ぶ領域に背景を付け、手順番号と補足案内を小さくする。マイページはプロフィール面と投稿一覧を分け、ショートカットを48px、タブの操作領域を44pxへ整える。
- 見た目を小さくしても検索入力は16px、主要な操作領域は44px以上を維持。AIキャラクター・非公開情報の説明やエラーは隠さない。

## スマホと一画面の情報量

739px以下では上ヘッダーを標準約56px、下ナビを56px＋端末の安全領域にする。下ナビは5つのアイコン中心とし、読み上げ用の名前・選択中の表示・48pxの操作領域を保つ。ロゴの「アイトック」は12pxを維持し、小さすぎる読み仮名にしない。

投稿は左右の外枠を外して横幅を活用し、写真は4:3。会員が添付した画像はcontainのままで内容を切らない。教材の文書・表の図版は別扱いにし、写真と同じ高さへ無理に詰めない。本文は16pxを保ち、前置き・補足・枠・余白を詰める。「はじめてのAI」は見出し横から常に開ける（右の案内が出るPCではそちらに集約）。PCの上バーは60px、左ナビは208pxとし、検索・学ぶ・マイページの余白も合わせて調整する。

## 動きと操作

最初の4投稿だけ240ms、最大60msの間隔で表示。操作の色は160ms、押下は100ms、戻りは180msを目安に揃え、写真の小さな拡大とタブ内容の短いフェードを中心にする。スマホ上下バーの背景ぼかしは外し、常時のスクロール監視や強制スクロールは追加しない。保存の反応はAPI成功後だけで、失敗時はエラーを表示する。

通常のリンク・同一ドメインの遷移を維持し、対応ブラウザーでのみ[View Transitions](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@view-transition)による180msのページ切替を加える。非対応環境では通常のページ遷移になる。旧教材ボタンの光沢はleftではなくtransformで動かし、装飾ホバーも動きを減らす設定の対象にする。実機でのFPS計測済みという意味ではない。

動きを減らす設定ではアニメーション・移動を止め、文言・枠・色で状態を伝えます。キーボードのフォーカス、強制配色、44pxの操作領域、小文字のコントラストも扱っています。

## データと確認範囲

### 9月6日：デザインとシステム設計の合同AIレビュー

読み取り担当2名が相互に候補を照合し、新機能の追加より「探す→読む→試す→保存」の詰まりを優先しました。実在の外部専門家との会議ではありません。

- 教科書検索は先頭12件だけで終わらず、検索語・対象を保ってページ送り。件数と表示範囲を小さく示し、0件では別の探し方へ案内。範囲外のページ指定は最終ページに収める。
- 投稿・教科書・メンバーのうち、選択中のタブだけ必要なデータを取得する。教科書の検索では投稿・保存・いいねのDB取得をしない。認証判定やキャッシュの境界は変えない。
- フォロー中が空のときは、ログイン／プロフィール設定／絞り込み解除／メンバー探しを状態別に1つ案内。すでに表示できる投稿を公開プロフィール設定で塞がない。
- 保存に成功した後だけ、操作列の下に「保存しました」と保存一覧リンク。自動では消さず、解除・再操作で更新する。失敗時は保存済みにせず、エラーを表示する。
- 有効な教材IDのある会員・公式AI投稿では「試す ↗」から新規タブへ。投稿の画像・タイトル・コメントへの入口も維持する。公式教材紹介は「準備」から既存の準備説明へ進み、重複していた末尾リンクを省く。

実装後レビューで、保存通知に対するgrid/flexの後勝ちを修正。通知はflexでも次行全幅とし、アイコン列に入り込まない指定を追加しました。`check:ui`に検索条件・ページ境界・空表示の分岐・保存通知の静的描画を追加。`scripts/check_discovery_http.ts`で読み取り8経路の応答・検索結果・教材リンクを確認します。実機の表示・FPS・クリック検証とは区別します。

マイページは大きなアバターと実数の投稿・フォロー数、その下に投稿グリッド／非公開の保存／学習／成果物／設定を置きます。切替中も既存フォームを保持し、学習・成果物・設定の直接リンクを維持。公開プロフィールとDMは[交流機能](AISTOCK_SOCIAL.md)の公開境界に従います。公式アカウントのアイコンは四芒星だけの丸から、深緑の角丸と「Ai」の文字を組み合わせた専用表示へ変更しました。

認証・保存一覧は各リクエストで取得し、カードには保存可能かとその投稿の保存状態だけを渡します。保存状態を含む公開ページにはキャッシュ禁止ヘッダーを設定し、公開ページの検索エンジン登録は妨げません。

`npm run check:ui`で主ナビの配下判定、公開ページの個人状態のキャッシュ禁止、背景の役割分け、本文・タブのサイズ指定、スマホの操作領域、主要な文字色のコントラストと動きのフォールバックを検査します。既存の認証・D1/R2検査とビルドも維持します。これらはソースとビルドの検査であり、ブラウザーの実操作・スクリーンショットによる視覚検証ではありません。実際の本番反映版・確認結果はHANDOFFと公開記録を参照してください。
