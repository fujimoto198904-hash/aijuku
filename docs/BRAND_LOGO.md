# 藤本実学塾 ロゴ運用

## ロゴの名称と意味

ロゴマークの名称は「学蝶紋（がくちょうもん）」です。

- 左右の羽は、誰でも読めるWeb教科書の二つの頁です。
- 中央へ向かう下端のV字は、教科書を開いた形と、学び始める場所を表します。
- 墨紺の羽と朱の背は、開いた本で学ぶことで自分の可能性が羽を持つ姿です。
- 細い朱の背は、学ぶ・試す・持ち帰る・聞く・直すを往復しながら上へ進む実践の道です。

「蝶を描いた飾り」ではなく「開いた本が蝶に見える塾章」として設計します。AIの脳、回路、ロボット、発光表現や羽模様を使わず、教育機関の品格と現代のデジタルサービスでの識別性を両立します。

## 正式ファイル

| ファイル | 用途 |
| --- | --- |
| `public/brand/fujimoto-jitsugaku-mark.svg` | 白・薄い背景用のロゴマーク |
| `public/brand/fujimoto-jitsugaku-logo.svg` | 白・薄い背景用の横組みロゴ |
| `public/brand/fujimoto-jitsugaku-mark-512.png` | SVGを使えない媒体向けの透明PNGマーク |
| `public/brand/fujimoto-jitsugaku-logo-1280.png` | SVGを使えない媒体向けの透明PNG横組みロゴ |

`public/brand/fujimoto-jitsugaku-butterfly-concept-v1.png`は画像生成による方向検討用です。正式使用は、縮小時の識別性と透明背景が安定する上記SVGを優先します。

## 色

- 墨紺: `#102A36`
- 人を表す朱: `#A94B3A`

サファイアは申込ボタンなど操作の色として残し、ロゴには使用しません。

## 使い方

- 通常はロゴマークと「藤本実学塾」の屋号を一緒に表示します。
- faviconや小さなアプリアイコンではロゴマークだけを使います。
- 濃紺や写真の上では色を反転せず、白磁の無地の台に通常色のロゴを載せます。
- ロゴの周囲には、マーク幅の4分の1以上の余白を確保します。
- 幅24px未満では使用しません。
- 比率、色、文字間隔を変更しません。
- 反転配色、影、グラデーション、縁取り、回転、羽模様を加えません。
