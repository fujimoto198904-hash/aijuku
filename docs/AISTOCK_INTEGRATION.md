# AIstock 統合の現在地

2026年9月5日。AIstockは、MON-aiが運営する無料のAI学習コミュニティです。藤本実学塾の募集サイトを、投稿を主役にしたアプリへ切り替えています。この文書を現在の仕様として扱い、過去の学校・Aitockデモの資料と混ぜないでください。

## 使い方のつながり

「投稿を見る → 保存する → 教科書で試す → 自分用ノートに残す → 希望したら共有する」。見る・教科書で学ぶのは登録不要。保存・記録・質問・返信は無料会員です。AIサービス側の無料／有料プランは教科書のマークで案内します。

| 入口 | 役割 |
| --- | --- |
| `/`・`/community` | 実際の会員投稿と、明記したMON-ai公式教材紹介のフィード。種別・ページ切替 |
| `/discover` | 投稿と教科書をキーワードで探す |
| `/posts/:id` | 公式紹介から、準備する教材・実際の課題へ進む |
| `/learn` | 初心者の最初の一歩。経験者は興味のある教材からでもよい |
| `/textbook`・`/textbook/explore`・`/textbook/lesson/:id` | 使い方・検索・本文を分離した既存の完成教材 |
| `/community/new`・`/community/:id` | 質問／便利な使い方／学習の記録を投稿。返信・本人削除・運営の非公開対応 |
| `/mypage/saved` | 気になる投稿の保存。教科書ブックマークとは区別 |
| `/mypage/notebook` | 本人だけの記録。任意で内容を確認し、別の公開投稿へコピー |
| `/mypage` | 教科書の進捗、本人の投稿、プロフィール、既存のスキル記録 |
| `/admin`・`/aikanri` | 運営の投稿確認・対応、登録設定状態、既存の成果物確認 |

## データと安全性

- 教科書730件・73章の正本は`lib/textbook-lessons/`。再生成・旧ワークツリーからの上書きはしていません。
- 投稿・返信・保存・自分用ノートはD1。画像本体はR2の`MEDIA`。未公開画像は本人だけ、公開投稿の画像は誰でも読めます。元投稿を非公開にすると画像の一般配信も閉じます。
- 添付は1枚。ブラウザーで画像を縮小してPNGに変換し、サーバーでも寸法・内容・容量を確認、位置情報などの付帯データを取り除きます。画像に写った個人情報は本人による確認が必要です。
- ノートは公開検索・通常の運営投稿一覧へ出しません。共有済みの公開投稿は独立したコピーで、ノート削除に連動しません。
- 新規登録は確認メールまたはGoogleの本人確認。その後8文字以上の自分用パスワードを設定。以前の会員ID・学習記録・ログインとの互換は維持します。メール一致だけで別アカウントを統合しません。
- 運営バッジはサーバーの権限で付与。ニックネームでのなりすまし、デモの書込み、本人以外のノート参照を拒否します。
- 公式紹介は架空の生徒投稿ではありません。写真・カード図版は教材紹介用のイメージ。実行済み成果物・学習効果の実測・架空の人気件数として扱いません。

## 停止した有料サービス

`lib/site-features.ts`の`paidServicesEnabled=false`を正とします。申込・決済開始・顧客ポータル・Calendar接続のAPIは410。ホーム、会員、管理、登録の旧画面は`features/paid-school/`へ隔離しました。Stripeの署名済みWebhookと過去データの保管は継続可能な形で残します。新たな課金を有効にするものではありません。

復元点はGitブランチ`codex/archive-paid-school-20260905`（3e63e24）。復活時は、現在の会員・教材・コミュニティを維持した上で旧サービスだけ再統合し、規約・料金・提供体制・決済を再確認します。ブランチ丸ごとの上書きや、フラグだけの本番切替は禁止です。

## 本番との境界

今回の統合先は`mon-ai.jp/aistock`ですが、新しいSites版と親Vercelのrewriteを組み合わせて切り替えるまで未公開です。Git pushだけで公開されたと表現しないでください。

Google登録・確認メールの実設定と実アカウントによる初回登録の通し確認が残っています。設定のない環境では「準備中」と表示します。認証情報はチャットやGitに貼らず、実行環境の秘密設定に入れます。外部連携が未確認のまま「誰でも登録できる」と案内しないでください。

公開時の順序：親サイトに`/aistock`内部転送を追加 → 既存Sitesへ同じプロジェクトIDで新バージョンを公開 → 正式ドメインで本文・画像・認証・APIを確認 → 旧`/aijuku`から同じ下層ページへ一時転送。Aitockの旧ドメインは本人のブラウザー記録を書き出せるまで一括転送しません。
