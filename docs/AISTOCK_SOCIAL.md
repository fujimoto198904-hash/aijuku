# AIstockの交流機能

2026年9月5日。ローカル実装・隔離データ検証。本番公開・実ブラウザー操作確認はまだ行っていません。

## できること

- 自分用マイページ：投稿グリッド、保存、学習、成果物、設定の切替。自分用ノートは別ページのまま非公開。
- 公開プロフィール：`/u/[handle]`。本人が名前・自己紹介・公開範囲・DM受信を選ぶ。公開後の新規投稿だけを紐付け、過去の別名投稿は自動でまとめない。
- フォローとフォロワー一覧、実数のいいね、会員／公式教材へのコメント、公開リンクの共有。
- フィード：おすすめ・フォロー中・みんな・教材・公式AI。おすすめでは会員投稿の間に教材紹介を挟む。
- 検索：18キーワードと投稿／教材／メンバーの切替。
- DM：`/messages`。受信許可のある実会員へ1通のリクエスト。相手が承認してから会話を続ける。本文のみ、1通2,000文字、1日100通まで。会話一覧は最新100件、1画面50通。サイトは仕事の斡旋・契約・決済の仲介をしない。
- ブロック・通報。過去のDMはブロック後も当事者が確認・通報できる。運営は通報された1通だけを確認し、他人の全DMを読む権限はない。

## データの境界

公開プロフィールはログイン会員とは別のテーブル。会員メール・認証IDを公開DTOへ渡さない。保存、学習、ノート、未公開成果物は公開ページへ渡さない。本人の設定を変えても既存スキル共有ページの同意・確認条件は緩めない。

POSTは同一送信元、認証、有効会員、現行規約同意、デモ不可、入力長、操作制限を検査する。DMの読む・送る・承認・通報ごとに当事者を検査。ブロックは公開投稿の閲覧を完全に隠す機能ではなく、交流を制限するもの。

マイページ・DM・APIはno-store/noindex。公開プロフィールとフィードも、個人のフォロー・いいね状態を含むためno-store。

## 公式と10人の公式AI

`lib/official-characters.ts`が人物像と投稿例の正本。全員が架空のキャラクターであり、公式AI表示を必ず付ける。写真は既存sozaiのイメージ素材で、写真の人物本人の投稿・推薦ではない。藤本本人の写真は使用しない。取得元・ライセンスの記録は未確認なので本番公開前に確認する。

`npx tsx scripts/seed_official_local.ts`は固定のローカルD1だけに、公式1＋公式AI10プロフィール、教材紹介6＋架空投稿例20件を作る。実際の作成日時と、過去の例示日を分離する。反応・フォロワー数は作らない。公式プロフィールはログイン会員IDを持たず、データ管理用memberにも認証アカウント・パスワード・セッションを作らない。

同じseedを繰り返しても重複せず、削除済み投稿を復活させない。本番で準備する場合は所有者の`/admin/social`から明示操作する。

## 投稿の自動化

`/admin/social`で、公式または公式AIを選び、確認済みの本文・課題・公開してよい日本時間を保存する。保存だけでは公開しない。現時点の実行は運営の「時刻を過ぎた確認済み投稿を公開」ボタン。取り消し可能、実行は冪等。作成・確認者を記録する。

トレンド取得・AI生成・定期スケジュールは未稼働。頻度・情報源・確認手順が決まってから、`publishDueOfficialPosts`を認証付き実行元へ接続する。未確認のトレンド記事を勝手に投稿しない。

## 検証と残りの確認

`npm run check:aistock`で隔離D1/R2・交流機能のAPIを検証。`check:ui`で混在順の欠落／重複とキャッシュ制御。`tsc --noEmit`と全体`verify`も実行する。

本番切替には公開承認、Google／確認メール設定、素材利用条件、正式ドメインで2人の実会員によるDM・フォロー・公開停止の確認が必要。予約投稿の定期実行は別の未設定事項。
