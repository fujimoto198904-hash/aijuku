# 藤本実学塾 ChatGPT実践教科書 やってみたいから選べる共通制作200

> 状態: 全面再設計案 / 採用前の精査用
> 改訂日: 2026年9月1日
> コンセプト: **AIを勉強するのではなく、作りたいものをAIと完成させる。**

全教材の役割、重複時の正本、コース間の乗換え方は、[カリキュラム全体地図](./TEXTBOOK_CURRICULUM_MASTER_MAP.md)を先に確認してください。

この共通編は、200問を最初から全部こなすための必修課程ではありません。**「こんなものまで作れるんだ」と思える、どの会社でも役立つ200個の制作体験**を集めています。レベルは人の優劣ではなく、作品が少しずつ頼もしくなっていく順番です。作りたいもの、今の仕事、使える環境に合わせて、気になる章から始めたり飛び級したりできます。

保存場所、プロジェクトとチャットの分け方、前章から次章への渡し方は、[学習構造案](./TEXTBOOK_LEARNING_STRUCTURE_DRAFT.md)にまとめています。同じ作品は同じプロジェクトで育てますが、10問を一本の長いチャットにはしません。`01〜03`、`04〜06`、`07〜10`の工程ごとにチャットを分け、最新の完成品と`ここまでメモ.md`だけを次へ渡します。

### 資料は、その仕事でいちばん簡単な方法で渡す

各課題の本文では、材料と作業画面を分けて示します。短いメール、チャット、箇条書きは本文をコピーして貼り、PDF、Word、Excel、画像等の書式付き資料は添付します。両方を一つの課題で使っても構いません。単発の下書きはChat、実ファイルを作る・同じ成果物を何度も育てる課題はWorkをすすめます。Workの入力欄でも、短文は貼り、書式資料は添付します。

AIが読めなければ、フォルダ参照のまま粘らず、同じChatまたはWorkの入力欄へファイルを添付し、それでもだめなら必要部分を貼ります。Workが表示されない環境では、Chatへの貼付・添付と本人による保存で同じ完成条件へ進みます。読めなかった資料名をAIに言わせ、見えない内容を推測させません。入力方法は採点せず、どの入口でも同じ完成条件で確認します。Chatの成果物は本人がコピーまたはダウンロードして保存し、Workの成果物はAIへ保存を頼んだ後に本人が開きます。

## 200問は、全員用・作る人用・AI推進用の3層から選べます

| レベル | 主に向いている人 | 手元に残るもの |

Lv.01〜60は「どの仕事にも共通」の基本メニューです。Lv.61以降は、作りたい人、または社内でAIを広げたい人が目的に合わせて選ぶ発展編です。**共通200という名前でも、200問全部が全員必修という意味ではありません。**

共通編で作りたい能力が見つかった後は、会社の担当機能を深掘りする[主要20部門×10チャレンジ](./TEXTBOOK_DEPARTMENT_TRACKS_200_DRAFT.md)、店・会社・専門分野の一連の仕事を作る[業種別10コース×10チャレンジ](./TEXTBOOK_INDUSTRY_TRACKS_100_DRAFT.md)、本・SNS・画像・動画・ゲーム・スマホアプリ・Excel等の一作品・体験を作り込む[生成特化23タイプ×10チャレンジ](./TEXTBOOK_GENERATION_TRACKS_200_DRAFT.md)から選べます。いずれも共通200の完走は前提ではありません。

## この本で作れるもの・専門コースへ渡すもの

- **担当する:** 会話、調査、ファイル、表、画面、DB、認証、承認、連携、安全、復旧を、難易度順に体験する。
- **担当しない:** 部署固有のKPIと責任、業種固有の規則、媒体ごとの専門的な編集・デザインを最終決定する。
- **重複した時:** 共通の合格版・開始見本を専門コースへ渡し、専門側では固有の判断と差分だけを加える。同じ基盤をゼロから作り直さない。
- **正本:** 共通技術の練習が主目的なら本書、実務部門・業種・媒体作品が主目的なら選んだ専門コースを正本にする。

## 作品が少しずつ頼もしくなる7つのステップ

| 難易度の軸 | 初期 | より高度な状態 |
|---|---|---|
| 一回 → 継続 | 一回動かす | 決まった頻度で継続して動かす |
| 自分 → 複数人 | 自分一人で使う | 複数人と役割を分けて使う |
| 画面 → DB | 画面だけを作る | 共有データベースへ安全に保存する |
| ローカル → 公開 | ローカルや教材内で試す | 公開範囲を決めて限定・本番公開する |
| 表示 → 承認後連携 | 結果を表示する | 人が承認した結果だけ外部へ反映する |
| 動く → 復旧可 | 正常時に動く | 停止、手作業復帰、バックアップ、復旧ができる |
| 作者のみ → 第三者引継ぎ | 作者だけが分かる | 第三者が運用、障害対応、移行、廃止までできる |

## 今の自分に合う、3つのスタート地点

- **中級ビジネスパーソン:** 会議後の作業ならLv.31、社内資料ならLv.41、自分用アプリならLv.61、共有業務ならLv.101から始める。

## 自分のペースで選べる3つの進め方

| ルート | 進め方 |
|---|---|
| **らくらく** | 完成見本の名前、色、文章、項目を交換する。教材データと教材環境だけで完成させる |
| **標準** | 機能、画面、計算ルールも変更し、正解付きテストで直す |
| **実務挑戦** | まず架空データで通し試験を完了する。その後、組織の許可が取れた人だけ、対象者・期間・データ・停止条件を限って実測する |

らくらくルートでも学習レベルは修了できます。会社の権限、有料プラン、外部アカウントがないことを不合格理由にしません。ただし、実際にどこまで動かしたかは次の実績バッジで区別します。

**課題の合格は、架空データの通し試験までできます。** `限定運用済み`は授業の言い換えではなく、会社の許可後に実際の対象で追加実施した別バッジです。架空データの処理時間を「実務の短縮時間」として報告しません。

| 実績バッジ | 証拠 |
|---|---|
| **教材モック修了** | 架空データと教材環境で画面・入出力・例外を確認した。常に「実DB・実認証・実送信は未接続」と表示する |
| **実接続検証済み** | 自分または許可済みのテスト環境で、DB・認証・通知等の接続、権限、解除を確認した |
| **限定運用済み** | 組織承認の下で対象者・期間・データを限定して使い、品質・時間・費用・事故を実測した |

## コードやデザインを手で作れなくても始められる

手書きコード、手作業のデザイン、ゼロからの表計算式作成を受講条件にしません。受講生はAIへ目的と条件を伝え、AIが作った画面・画像・文書・仕組みを実際に触り、失敗を見つけ、追加指示で直します。

ただし、業務の事実、本人や相手の同意、利用するアカウント、契約、送信先、公開・支払・採否・権限変更の承認は人が担います。AIに事実や許可を創作させることは「AIのみ」ではありません。

ChatGPTが制作を手伝うことと、公開アプリの中でAIが自動実行されることも別です。実動版には承認済みのAI実行基盤、認証情報の安全な保管、利用件数・費用の上限、秘密情報の取扱いが必要です。教材内で人がAI役を再現した版は「AI自動実行済み」には数えません。

| タグ | 意味 |
|---|---|

| **検索** | Webを調べ、出典と確認日を残す |

| **データ** | 表、CSV、計算、グラフ等を扱う |
| **試作** | コードや画面をAIに制作させ、実際に触って直す |
| **定期実行** | 日時や条件を決め、繰り返し動かす |

## 安心して使える仕組みも、作品の一部にしよう

安全を「気を付ける」で終わらせません。作品へ、根拠と更新日の表示、確認待ち、人の承認、最小権限、変更履歴、緊急停止、手作業への切替、バックアップと復旧、データ書出し・削除を、必要な段階で実装します。

## 本の1ページにするとき、毎回つけるもの

1. **今日はこれを作る:** 課題名ではなく、今日手元に残る画面、画像、文書、ファイル形式と最初の完成までの目安。
2. **使うもの・今回はどう渡す:** 材料は短文なら貼り、見た目や表が大事なら添付する。作業画面は一回ならChat、実ファイルを作って何度も直すならWorkと分けて示し、追加資料を使うなら先に名前と理由を示す。
3. **まずこう言ってみる:** 長い説明ではなく、普段の話し方に近い最初の一言。
4. **出てきた物を実際に触る:** 開く、数字を変える、ボタンを押す等、受講者本人が行う一つの操作。
5. **出力を上げるコツ:** 三つ以内から、気になる一つだけ選んで使う短い一言。
6. **やりがちなミス:** 勝手に増えた名前や数字、見落とし、送信・公開前に止める所。
7. **ここまでできたら完成:** 開けた、使えた、合っていた、止まれた、保存できた、から本問に必要な三条件。通常チャット・添付は本人が保存し、WorkはAIへ保存を頼んだ後に本人が開く。
8. **自分の仕事なら:** 会社名、相手、商品、場面の一つだけを替える小さな応用。新しい機能や次の課題はここへ混ぜない。
9. **困ったら藤本に聞く:** 画面、課題名、使ったファイル、止まった所をまとめる短い相談メモ。
10. **ステップアップ:** 今回の完成品を使う次の課題IDまたは総仕上げ、一つの目的として便利になる内容、同じ会話へ送る短い一言。任意であり、現在の課題の合否には含めない。

## Lv.01–10｜まず10問、仕事を助ける「私のAI秘書」を育てよう

- **Lv.01｜仕事の話をすると、私らしく手伝ってくれるAI秘書を作ろう** — やってみること: 用意された選択肢から、呼ばれたい名前、仕事、よく作る文章、好みの長さ、避けたい表現を答え、ChatGPTへの初期設定文を完成させる。できあがるもの: そのまま再利用できる「私のAI秘書設定カード」。〔会話〕
- **Lv.02｜「何をしている人？」が30秒で伝わる自己紹介を作ろう** — やってみること: Lv.01の情報を使い、名刺交換やオンライン会議で読める50字と150字の自己紹介を作る。できあがるもの: 短い自己紹介と詳しい自己紹介の2種類。〔会話〕
- **Lv.03｜初対面でも「どんな会社？」がすぐ伝わる紹介文を作ろう** — やってみること: 穴埋め例を使い、「誰の、どんな困りごとを、どう助けるか」が伝わる紹介文を作る。できあがるもの: 会社・仕事の一言紹介と200字紹介。〔会話〕
- **Lv.04｜会う相手に合わせて、同じ魅力が伝わるプロフィールを作ろう** — やってみること: Lv.02–03を、顧客、採用候補、取引先向けに書き分け、事実は変えず言葉だけを調整する。できあがるもの: 相手別プロフィール3種類。〔会話〕
- **Lv.05｜走り書きのメモを、送信前のメールにしてみよう** — やってみること: 教材の箇条書きメモを、件名、お願い、期限または「未定」が分かるメールへ変え、元メモにない約束が増えていないか比べる。できあがるもの: 送信せずに保存した「メール.md」と未確認事項。〔会話・人の確認〕
- **Lv.06｜催促やお詫びも、角が立たない言い方にしてみよう** — やってみること: 教材の3場面から一つを選び、背景、お願い、期限、未確認事項を含む丁寧な文案を作る。できあがるもの: 依頼、催促、お詫びのうち一つの実用テンプレート。〔会話・教材環境可・人の確認〕
- **Lv.07｜ごちゃごちゃのメモから、今日やることを並べてみよう** — やってみること: 教材の一日分メモから、やること、期限、相手、必要な準備、確認待ちを抜き出す。できあがるもの: 優先順位付きの今日のToDo表。〔ファイル・教材環境可〕
- **Lv.08｜朝開くだけで、今日の予定と仕事が分かる一枚を作ろう** — やってみること: 予定、ToDo、確認待ち、今日一番大事なことを一画面へまとめる。できあがるもの: 印刷または画面保存できる「今日の朝ブリーフ」。〔ファイル・教材環境可〕
- **Lv.09｜顔写真がなくても、仕事が伝わる名刺風カードを作ろう** — やってみること: 教材テンプレートへ自己紹介、会社紹介、連絡方法、色を入れ、事実と誤字を確認する。できあがるもの: 画像またはPDFのプロフィールカード。〔ファイル・画像・人の確認〕
- **Lv.10｜明日から使える「私のAI秘書セット」を完成させよう** — やってみること: Lv.01–09から、AI秘書設定、プロフィールカード、メールテンプレート、ToDo表、朝ブリーフを一つのフォルダへまとめ、他人が見ても使い方が分かる表紙を付ける。できあがるもの: 仕事初日から使えるAI秘書スターターパック。〔ファイル・人の確認〕

## Lv.11–20｜告知・SNS・表紙に使える「伝わる一枚」を作ろう

> ここでは、告知画像、資料表紙、SNS画像、YouTubeサムネイル等から一つを選び、画像制作の共通基礎を体験する。YouTube固有の動画との整合、ロゴ・商標・複数接点のブランド設計は、生成特化YTB・IMG・BRDで深める。

- **Lv.11｜告知・SNS・資料表紙に使える「一枚の設計カード」を作ろう** — やってみること: 告知、資料表紙、SNS、YouTube等の見本または自分の安全な題材から一つ選び、見る人、伝えたいこと、使う場所を穴埋めする。できあがるもの: 1ページの一枚画像企画カード。〔会話〕
- **Lv.12｜見た瞬間に自分の仕事らしさが伝わる3色を選ぼう** — やってみること: 用意された配色見本から一組を選び、背景、主役、強調に使う色を決める。できあがるもの: そのまま見ながら使える3色の見本。〔ファイル・画像〕

- **Lv.200｜ほかの人へ安心して渡せる「会社のAI仕事システム」を完成させよう** — やってみること: 目的、利用者、データ、AI、権限、承認、連携、監視、費用、契約を一式にし、データ書出し、接続解除、認証情報失効、削除、手作業復帰、廃止訓練まで行う。できあがるもの: 公開または教材内の卒業システム、紹介デモ、評価結果、運用・復旧・移行・廃止パック、第三者の訓練証跡。〔AI実行基盤・外部接続・公開・組織承認・教材環境可・人の確認〕

## 使える機能が違っても大丈夫

- 毎朝6時などの正確な時刻に自動で動かせるかは、利用プラン、端末、地域、作業画面、通知設定で変わる。利用できない場合は「毎朝できた」とせず、保存した一言で自分から新聞を作る版を使う。
- 複雑な共有データベース、認証、複数人の会話、LINE連携は、外部のテスト環境やアカウントが必要になる。組織の許可がない場合は教材環境で行う。
- Webサイト・内部アプリの制作・公開例は[ChatGPT公式の活用例](https://learn.chatgpt.com/use-cases)にもあるが、接続できるデータ、認証、公開範囲、利用可能な生成形式は環境と時期で変わる。課題開始時に実際の画面を確認し、要件を満たさない場合は教材環境または承認済みの別テスト環境を使う。
